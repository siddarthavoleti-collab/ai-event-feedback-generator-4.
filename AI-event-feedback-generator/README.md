# AI Event Feedback Form Generator

AI-powered Google Apps Script web app that takes an event description, generates event-specific feedback questions with Gemini, and builds a real Google Form.

## Files
- Code.gs
- Index.html
- appsscript.json

## Setup
1. Create/open a Google Apps Script project.
2. Add these three files.
3. In Project Settings → Script Properties, add:
   GEMINI_API_KEY = your Gemini API key
4. Deploy as a Web app.
5. Execute as: Me
6. Who has access: Anyone

The API key is NOT included in this repository.
